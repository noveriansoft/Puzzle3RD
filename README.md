# 3D Puzzle Game

## Game Overview
Game where we go into a mart and do our "shift" as card player, then go home... or not.
This game has 2 Endings, Good and Bad, if you want the Good Ending, just follow the objective.
if you want the Bad Ending, open the trashcan behind the mart, thats all.

## How to Run
- Extract the rar files
- run exe file
- Play
